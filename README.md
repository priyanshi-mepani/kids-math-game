# Kids' Maths Game

## About the Project
The Kids' Maths Game is a mobile application project developed as part of my BTEC IT Mobile Application unit. It is designed to support children's maths learning through an interactive mobile experience.

## Project Purpose
The aim of this project was to apply mobile application development skills to create a maths-focused application for children.

## Project Type
- **Category:** Mobile Application
- **Course:** BTEC IT
- **Unit:** Mobile Application
- **Platform:** Android

## Application File
The Android application package (APK) is included in this repository so the application can be downloaded for testing.

**File:** `kids-math-game.apk`

## Learning Outcomes
Through this project, I gained experience in:
- Developing a mobile application for a specific audience
- Applying problem-solving skills during application development
- Understanding the process of packaging an application for Android
